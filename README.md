## Project Overview

**GroupDNA** is an end-to-end conversational analytics tool designed to process raw WhatsApp group chat export files (`.txt`) and extract behavioural patterns, hourly rhythms, response latencies, vocabulary obsessions, and distinct personality archetypes.

Behind its friendly presentation lies genuine data science: text mining, tokenization, time-series binning, multi-dimensional matrix operations, and greedy exclusive bipartite archetype assignment.

---

## Architectural Discipline: What Was Allowed & Forbidden

This project enforces strict **Week 1 Python fundamentals and NumPy** discipline. Engineering under intentional constraint builds fundamental mastery and highlights the ability to write robust algorithms from basic building blocks.

| Category | Allowed Resources | Strictly Forbidden |
| :--- | :--- | :--- |
| **Data Structures** | Core Python variables, lists, tuples, sets, plain dicts, comprehensions | `pandas` (no DataFrames, no `read_csv`), `polars` |
| **Counting / Aggregation** | Pure dicts using `.get()` and membership tests (`in`) | `collections.Counter`, `collections.defaultdict` |
| **String / Text Mining** | String methods (`split`, `strip`, `lower`, `upper`, `startswith`, `endswith`, `replace`, `isupper`, `isdigit`, `isalpha`, `count`, `find`) | `re` (regular expressions), `nltk`, `spacy`, NLP packages |
| **Numerical Computing** | `numpy` (`zeros`, `array`, `reshape`, `sum`, `max`, `min`, `mean`, indexing, slicing) | Pre-built WhatsApp analyzer libraries, machine learning frameworks |
| **Visualization** | Text-based terminal typography and block characters (`█`, `▒`, `░`, `.`) | `matplotlib`, `seaborn`, `plotly`, `altair` |
| **Time Handling** | Standard `open()`, `from datetime import datetime, timedelta` (`strptime`, `total_seconds`) | Any external date parsers (`dateutil`, `arrow`, etc.) |

## 7-Day Engineering Build Log

### Day 1: Setup & Robust Parser Engineering
- **Milestone:** Parsed `hostel_bois.txt` line-by-line while resolving real-world chat export anomalies.
- **Challenges:** Stitched continuation lines across multi-line messages without regular expressions using an 8-character `NN/NN/NN` date validator (`is_date_header`). Filtered out system messages (no sender colon), categorized `<Media omitted>` entries, and tracked deleted messages per participant.
- **Checkpoint:** Exactly **3,174 real messages**, 6 participants, 60 days, 4 system notices, 32 media omitted, and 15 deleted messages.

### Day 2: Group Overview & Volume Ranking
- **Milestone:** Computed date ranges, total active days, and sorted participant volumes.
- **Implementation:** Formatted human-readable date bounds (01 April 2024 to 30 May 2024) and ranked message totals from highest to lowest with accurate percentage distributions.
- **Checkpoint:** Rahul (953 msgs, 30.0%), Priya (718 msgs, 22.6%), Neha (635 msgs, 20.0%), Aman (490 msgs, 15.4%), Karan (354 msgs, 11.2%), Vikas (24 msgs, 0.8%).

### Day 3: Stop-Words Dictionary & Vocabulary Mining
- **Milestone:** Built a custom tokenizer using string splitting, punctuation stripping, and a custom stop-words dictionary.
- **Checkpoint:** Extracted group-wide Top 10 words and Top 5 words per individual. Verified that signature Indian college slang (`bhai`, `scene`, `yaar`, `kya`, `guys`) ranked prominently in the group's vocabulary.

### Day 4: 2D NumPy Activity Matrix & Shading Heatmap
- **Milestone:** Allocated a $6 \times 24$ `np.zeros` integer matrix mapped to participant indices and hour integers (0–23).
- **Implementation:** Used NumPy row sums (`matrix.sum(axis=1)`) to verify row totals. Rendered terminal text heatmaps with 4 shading tiers (`.`, `░`, `▒`, `█`) relative to each member's peak activity. Highlighted Aman's overnight concentration and Vikas's silence.

### Day 5: Response Latency & Silent Streak Detection
- **Milestone:** Parsed timestamps with `datetime.strptime(ts, '%d/%m/%y, %H:%M')` and measured inter-member conversational reply latencies.
- **Implementation:** Tracked consecutive zero-message calendar days. Detected Vikas's 11-day silence streak (23 April to 03 May) and confirmed Priya maintained 0 silent days.

### Day 6: Personality Archetype Detection & Exclusive Assignment
- **Milestone:** Implemented 8 modular scoring functions plus 1 bonus archetype (**The Late-Night Philosopher**).
- **Tie-Breaking Algorithm:** Normalized raw metrics against archetype scale thresholds and applied greedy exclusive assignment to prevent duplicate roles.
- **Checkpoint:** 
  - Rahul $\rightarrow$ THE SPAMMER (avg 4.5 msgs in a burst)
  - Priya $\rightarrow$ THE GROUP MOM (621 caring keywords)
  - Aman $\rightarrow$ THE NIGHT OWL (79.8% messages between 23h–04h)
  - Karan $\rightarrow$ THE STORYTELLER (avg 57.0 words/msg)
  - Neha $\rightarrow$ THE DRAMA QUEEN (63.3% drama messages)
  - Vikas $\rightarrow$ THE GHOST (silent on 44 of 60 days)

### Day 7: Formatting Polish, Edge-Case Hardening & Final Submission
- **Milestone:** Styled the 60-column terminal executive report using box-drawing characters and aligned f-string specifiers.
- **Testing:** Executed a stress-testing test suite covering empty chats (0 messages), single-participant chats, and the full 3,174-message dataset. Verified zero division-by-zero crashes and confirmed 100% compliance with zero forbidden imports.

## How to Run

### Option A: Running in Google Colab
1. Open [Google Colab](https://colab.research.google.com).
2. Upload `GroupDNA_<FirstName>_<RollNumber>.ipynb`.
3. In the left sidebar, click the **Folder icon** and upload `hostel_bois.txt` (or your own WhatsApp exported `.txt` chat).
4. Run all cells (`Runtime` $\rightarrow$ `Run all` or `Ctrl + F9`).
5. The notebook automatically detects `/content/hostel_bois.txt` as a fallback.

### Option B: Running Locally (Jupyter Lab / Notebook / VS Code)
1. Ensure Python 3.8+ and NumPy are installed:
   ```bash
   pip install numpy jupyter
   ```
2. Place `hostel_bois.txt` in the same directory as the notebook:
   ```
   GroupDNA/
   ├── GroupDNA_<FirstName>_<RollNumber>.ipynb
   ├── hostel_bois.txt
   └── README.md
   ```
3. Launch Jupyter:
   ```bash
   jupyter notebook GroupDNA_<FirstName>_<RollNumber>.ipynb
   ```
4. Click **Run All Cells**.
